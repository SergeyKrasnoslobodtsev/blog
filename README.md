# Блог: компьютерное зрение и CAD

Заметки и посты в формате «проблема → решение» о компьютерном зрении и распознавании CAD-деталей (STEP).

## Структура

```
inbox.md        быстрые заметки «что сломалось и как починил»
ideas.md        темы на будущее
plan.md         контент-план
drafts/         черновики (шаблон — drafts/_template.md)
posts/          опубликованное
assets/         картинки, схемы, «до/после»
.vscode/        проверка орфографии и markdownlint
```
